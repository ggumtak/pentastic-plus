# 펜스틱 (Pentastic)

갤럭시 탭 + S펜으로 Anki 일본어 카드를 보다가 막히는 부분을 바로 Claude에게 묻는 앱.

**사용 흐름**: S펜 버튼 길게 누르기 → 화면이 멈춤 → 펜으로 질문할 부분 드래그 → 고른 부분 바로 아래(공간이 없으면 위/옆)에 작은 카드가 뜸 → `해석·문법` / `한자 예시` / `단어 뜻`을 누르거나 아래 칸에 직접 질문.

- 카드는 Anki 위에 떠 있고, 카드 바깥은 그대로 Anki를 조작할 수 있습니다. 윗부분을 잡고 끌어서 옮기고, `✕`로 닫습니다.
- 버튼이나 보내기를 누르기 전에는 아무것도 전송되지 않습니다. (설정에서 '드래그하자마자 바로 물어보기'를 켜면 자동으로 해석·문법을 요청합니다.)
- 답을 받은 뒤 같은 카드에서 이어서 물어볼 수 있습니다.
- 카드의 **＋ 캡처** 버튼, 카드 위에서 S펜 버튼 누르기, 또는 펜 버튼 길게 누르기 → 카드는 그 자리에 둔 채 새로 캡처해서 같은 대화에 붙입니다. 새 대화를 시작하려면 `✕`로 닫고 다시 캡처하세요.

## 설치 (한 번만)

1. 탭에서 이 주소를 엽니다: <https://github.com/ggumtak/pentastic-plus/releases/latest/download/pentastic.apk>
2. 내려받은 `pentastic.apk`를 누릅니다. "출처를 알 수 없는 앱" 경고가 나오면 브라우저(또는 내 파일)에 설치 허용 → 설치.
3. 앱 목록의 **펜스틱** 아이콘을 누르면 설정 화면이 열립니다. 화면의 4단계를 따라 하세요.
   1. 접근성 → 설치된 앱 → **펜스틱 화면 캡처** 켜기
   2. Claude API 키 붙여넣기 → 키 저장 (키: console.anthropic.com → API Keys, 사용 전 Billing에서 크레딧 충전 필요)
   3. 모델: Haiku 5.5 (기본)
   4. 설정 → 유용한 기능 → S펜 → 에어 액션 → **펜 버튼 길게 누르기** → 펜스틱

**안 뜰 때**: 앱 목록에서 펜스틱 아이콘을 눌러 보세요. 캡처 화면이 뜨면 앱은 정상이고 에어 액션 연결(4단계)만 다시 확인하면 됩니다. 설정 화면이 뜨면 접근성이 꺼져 있는 것입니다. 접근성 스위치가 회색으로 막혀 있으면 설정 → 애플리케이션 → 펜스틱 → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시 켜세요 (안드로이드 13이 스토어 밖에서 설치한 앱에 거는 보호 장치).

**프롬프트 바꾸기**: 설정의 '답변 방식 (프롬프트)'에서 Claude에게 주는 지시문을 직접 고칠 수 있습니다. [기본값으로 되돌리기]로 원래대로 돌아갑니다.

설정이 끝난 뒤 아이콘을 누르면 설정 화면이 아니라 바로 캡처가 시작됩니다. 설정을 다시 열려면 아이콘을 길게 눌러 `펜스틱 설정`을 고르거나, 카드의 `⚙`를 누르세요.

## 비용 (추정)

질문 1건에 이미지 + 질문 + 답변을 합쳐 대략 입력 2천, 출력 6백 토큰 정도로 잡으면:

| 모델 | 단가 (입력/출력, 100만 토큰당) | 1건 대략 |
|---|---|---|
| Haiku 5.5 (기본) | $0.10 / $0.50 | 약 $0.0005 (1원 안팎) |
| Sonnet 5.5 | $2 / $10 | 약 $0.01 (15원 안팎) |

실제 사용량은 console.anthropic.com → Usage에서 확인할 수 있습니다.

## 업데이트

같은 주소에서 새 APK를 받아 설치합니다. 지금은 빌드마다 서명 키가 달라서, **새 버전을 설치하려면 기존 앱을 먼저 삭제**해야 합니다 (API 키와 접근성 권한을 다시 설정해야 함). 저장소 Secrets에 고정 서명 키(`SIGNING_KEYSTORE_B64`, `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD`)를 넣으면 덮어쓰기 업데이트가 됩니다.

## 개인정보

- 드래그해서 고른 부분의 이미지와 질문만, 질문을 보낼 때 Anthropic API로 전송됩니다.
- API 키는 탭의 앱 내부 저장소에만 저장되고 백업되지 않습니다.
- 접근성 권한은 화면 캡처에만 쓰며, 다른 앱의 내용을 읽거나 저장하지 않습니다.

## 구조 (개발용)

| 파일 | 역할 |
|---|---|
| `TriggerActivity` | 런처/에어 액션 진입점. 화면 없이 캡처 요청 후 종료 |
| `CaptureService` | 접근성 서비스. `takeScreenshot()`으로 캡처, 선택 오버레이, 떠 있는 카드 표시. SDK 클래스와 API 연결을 미리 데워 둠 |
| `SelectionView` | 멈춘 화면 위에서 드래그로 사각형 선택 |
| `FloatingPanel` | 떠 있는 질문 카드. 빠른 질문 버튼, 직접 입력, 스트리밍 답변, 이어 질문, 끌어서 이동, 라이트/다크 |
| `ClaudeTutor` | Claude API 호출 (anthropic-java SDK). 시스템 프롬프트, 대화 기록, 오류 메시지 |
| `SettingsActivity` | 접근성·API 키·모델·에어 액션 안내 |

빌드: GitHub Actions(`.github/workflows/build.yml`)가 푸시할 때마다 APK를 만들어 `latest` 릴리스에 올립니다. 최소 Android 11 (API 30).
